# Варианты моделей и параметры рассуждений (Reasoning/Thinking)

В этом документе описывается, как плагин работает с параметрами рассуждений (цепочками мыслей/thought blocks) в моделях Сбера и как осуществляется маппинг параметров OpenAI.

---

## 1. Параметры рассуждений GigaChat

Флагманские модели Сбера (такие как `GigaChat-Max`) поддерживают режим глубоких рассуждений перед выдачей финального ответа. 

Сетевой транслятор плагина обрабатывает параметры рассуждения на лету, преобразуя их из спецификации OpenAI в формат GigaChat.

### Маппинг параметров рассуждений

Поскольку официальный REST API GigaChat от Сбера на данный момент не поддерживает параметры `reasoning_effort` или `thinking` в JSON-схеме запроса (их прямая передача приведет к ошибке `400 Bad Request` на строгом шлюзе Сбера), плагин реализует умную трансляцию через **промпт-инжиниринг**:

1.  **Вырезание параметров**: Плагин автоматически удаляет поля `reasoning_effort` и `thinking` из тела запроса перед его отправкой на сервера Сбера.
2.  **Внедрение системных инструкций**: На основе переданных параметров плагин преобразует уровень рассуждений в скрытые системные инструкции (добавляя или обновляя сообщение с ролью `system`):
    *   `high` (или `budget_tokens` $>$ 1024) $\rightarrow$ Добавляет инструкцию: `"\n[Системное руководство: Проанализируй задачу очень подробно, составь детальный пошаговый план решения и проведи глубокие рассуждения (Chain-of-Thought) перед тем, как выдать финальный ответ.]"`
    *   `medium` (или `budget_tokens` $\le$ 1024) $\rightarrow$ Добавляет инструкцию: `"\n[Системное руководство: Подумай пошагово перед тем, как выдать итоговый ответ.]"`
    *   `low` $\rightarrow$ Рассуждения не форсируются, модель отвечает в обычном режиме.

Это позволяет активировать цепочку пошаговых рассуждений (Chain-of-Thought) на уровне самой модели (особенно эффективно на флагманской `GigaChat-Max`), сохраняя совместимость с API.

## 2. Использование вариантов (Variants) в `opencode.json`

В файле настроек `opencode.json` вы можете создать именованные варианты с предустановленными параметрами рассуждений. Это позволяет быстро переключаться между ними в командной строке.

### Пример описания вариантов:

```json
"GigaChat-Max": {
  "name": "GigaCode Max (Flagship)",
  "limit": { "context": 128000, "output": 8192 },
  "modalities": { "input": ["text", "image"], "output": ["text"] },
  "variants": {
    "low": {
      "options": {
        "reasoning_effort": "low"
      }
    },
    "max": {
      "options": {
        "reasoning_effort": "high"
      }
    }
  }
}
```

### Запуск модели с конкретным вариантом:
В терминале OpenCode вы можете вызвать модель с нужным уровнем рассуждений с помощью флага `--variant`:
```bash
opencode run "Напиши сложный алгоритм сортировки" --model=gigachat/GigaChat-Max --variant=max
```
При этом плагин автоматически применит параметр `reasoning_effort: "high"`.

## 3. Вывод цепочки рассуждений (Reasoning Output)

Модели `GigaChat-Max` и `GigaChat-2-Max` возвращают процесс размышлений в поле `reasoning_content` (как в стандартном ответе, так и в потоковом стриминге чанков). 

Плагин автоматически перехватывает это поле и транслирует его в OpenAI-совместимый параметр `choices[0].message.reasoning_content` (или `choices[0].delta.reasoning_content` при стриминге). Это позволяет клиентам OpenCode отображать и визуализировать ход мыслей модели перед выводом финального ответа.
